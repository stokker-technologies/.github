# Stokker Technologies

We build software and hardware tools for engineering: test orchestration,
application runtimes, circuit simulation, and embedded systems.

## Open Source

| Project | Scope |
| --- | --- |
| [Dokime](https://gitlab.com/stokker-technologies/open-source/dokime) | Run hardware and software test procedures, capture measurements, and keep the execution evidence. |
| [Harmos](https://gitlab.com/stokker-technologies/open-source/harmos) | A Rust application runtime with journaled state, replay, undo, and recovery. |
| [Helios Node Mesh](https://gitlab.com/stokker-technologies/open-source/helios-node-mesh) | RP2040 node firmware and Rust and Python interfaces for USB and LoRa control. |

Development is hosted on GitLab. Each project documents its supported workflows,
constraints, and contribution process in its repository.
